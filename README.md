# crazy-UX

Independent interaction/motion study based on the UX language of experimental award-winning studio sites.

The build is intentionally self-contained: one `index.html`, no package manager, no runtime dependencies.

Implemented interaction systems:
- staged loader / entrance
- black + blush split visual language
- draggable inertial world
- procedural wireframe sphere
- floating depth cards and pointer parallax
- click-and-hold transition
- sound toggle / ambient tone
- full-screen animated menu
- selected-project index with filters and hover previews
- contact scene
- dedicated touch/mobile layout
- `prefers-reduced-motion` fallback

This repository is an independent visual/interaction study and does not contain copied source code or proprietary project media from the reference studio.
